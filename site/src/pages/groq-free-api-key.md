## Steps

1. Go to **console.groq.com/keys** and sign in, or create a free account.
2. Click **Create API Key**, give it a name like "Reply Better AI", and confirm.
3. Copy the key. Groq shows it only once, so paste it somewhere safe if you want to keep it.
4. In Reply Better AI, open **Settings → Engine → Groq** and paste the key.
5. Click into any message box and try it.

That's it. The settings page shows how many requests you have left today, read straight from Groq.

## Keep your key safe

- Don't share the key or paste it into websites. Anyone with it can use your Groq quota.
- If you think it leaked, delete it on the Groq keys page and create a new one.
- Reply Better AI keeps the key in the extension's background worker. Web pages you visit can't read it.
